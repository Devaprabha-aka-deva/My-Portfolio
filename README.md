# 🌐 Personal Portfolio Website

This is a responsive and interactive personal portfolio website showcasing skills, projects, and recommendations. Built using HTML, CSS, and JavaScript, this site serves as a dynamic resume.

## 📌 Features

- 💼 "About Me" section describing academic background and goals.
- 🧠 Skills section with icons and experience levels in HTML, CSS, JavaScript, Python, Java, and C.
- 📁 Project highlights including:
  - **Doctor-Patient Appointment System** using Java
  - **Autonomous Path-Navigation Robot**
  - **Bi-Axial Solar Tracker**
- 📝 Real-time recommendation submission feature with pop-up confirmation.
- 🔝 Scroll-to-top floating action button.
- 📱 Fully responsive layout and clean design.

## 🛠️ Tech Stack

- **HTML5** — Structure
- **CSS3** — Styling and layout
- **JavaScript** — Dynamic interaction and DOM manipulation
